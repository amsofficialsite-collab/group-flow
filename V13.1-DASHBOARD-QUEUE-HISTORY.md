# GROUP FLOW V13.1 — Dashboard / Daily Queue / Posting History

## Changes
- Dashboard refreshes automatically with Supabase Realtime and a 15-second fallback refresh.
- Dashboard separates remaining queue today, currently posting, posted today, and failed today.
- Daily Queue loads only `pending` / `posting` jobs.
- Completed/failed/skipped jobs no longer remain in Daily Queue.
- Upcoming queue is grouped by day and sorted current → future.
- Past `pending` jobs are not mixed into the main queue; a warning count is shown as overdue.
- Posting History shows date/time, group, content, result, notes, and post URL and refreshes automatically.
- Fixed server-side posting log ownership: service-role finish callback now writes `user_id` from the queue row. This fixes a cause of missing Posting History rows when `posting_logs.user_id` is NOT NULL.
- Added Realtime publication setup and indexes to `supabase/v13_stability.sql`.

## Required database step
Run the updated `supabase/v13_stability.sql` in the existing Supabase project's SQL Editor before deploying this build.

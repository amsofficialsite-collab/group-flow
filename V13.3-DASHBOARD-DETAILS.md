# GROUP FLOW V13.3 — Clickable Dashboard Details

## What changed
- Every Dashboard statistic card is clickable.
- Details open in a modal without leaving Dashboard.
- Groups: name, category/province, members, active state, Facebook link.
- Content: title, category, status, last updated.
- Today queue: scheduled time, group, content, Profile/Page identity, retry/error.
- Posting: current jobs with identity and retry state.
- Posted today: time, group, content, identity, post URL.
- Failed today: time, group, content, identity, error/notes.
- Detail modal follows Queue/Posting History realtime changes.

## Database
No new Supabase migration is required for V13.3. Continue using the V13.2 schema.

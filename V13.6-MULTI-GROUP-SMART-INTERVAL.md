# GROUP FLOW V13.6 — Multi Group + Smart Interval

## Added
- Select multiple Facebook Groups in one queue creation flow.
- Select All / Clear group selection.
- Smart posting interval presets: simultaneous, 2, 5, 10, 15, 30 minutes, plus custom minutes.
- Works with both single schedule and multi-day / multi-time schedule.
- Queue Preview shows the exact group and posting time before creating jobs.
- Each group is still stored as its own queue item, so status, retry and history remain independent.

## Example
Start 09:00, 5 groups, interval 5 minutes -> 09:00, 09:05, 09:10, 09:15, 09:20.

## Database
No new Supabase migration is required for this feature.
